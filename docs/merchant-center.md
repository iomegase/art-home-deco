# Merchant Center readiness

## 1. Prerequis Merchant Center
- Domaine verifie
- Informations entreprise completes
- Politique de livraison accessible
- Politique de retour accessible

## 2. Donnees produits necessaires
- ID produit stable
- Titre et description clairs
- Prix en EUR
- Disponibilite (in stock / out of stock)
- Image principale de bonne qualite
- URL produit canonique

## 3. Pages legales necessaires
- Mentions legales
- CGV
- Politique de confidentialite
- Livraison et retours

## 4. Flux produit futur
- Source possible: export backend ou flux API
- Champs minimaux: `id`, `title`, `description`, `link`, `image_link`, `price`, `availability`, `brand`, `condition`

## 5. Donnees structurees Product
- Deja presentes sur page produit (`Product`, `Offer`)
- A maintenir a jour avec prix/stock reel

## 6. Checklist avant soumission
- Produits actifs accessibles publiquement
- Prix/stock coherents front et backend
- Images valides
- Delais/frais livraison publies
- Retours/CGV publies
- Tests Rich Results OK
