# Livraison et Colissimo

## Classes
| Classe | Usage | Poids estimé |
|---|---|---:|
| XS | très petit objet | 250 g |
| S | petit objet déco | 500 g |
| M | objet moyen | 1 kg |
| L | lampe/vase moyen | 2 kg |
| XL | volumineux/fragile | 5 kg |
| PICKUP_ONLY | miroir/meuble | aucun envoi |

## MVP
- Retrait boutique gratuit.
- Colissimo calculé par classe.
- Étiquette générée manuellement dans ColiShip.
- Tracking ajouté manuellement dans l’admin.

## Plus tard
API Colissimo : étiquette, point retrait, suivi colis.
