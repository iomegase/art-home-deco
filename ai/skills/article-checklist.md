# Checklist SEO Article

Avant publication, vérifier :

## Métadonnées

- [ ] title SEO présent
- [ ] title sans marque dupliquée
- [ ] meta description unique
- [ ] canonical générée
- [ ] og:title présent
- [ ] og:description présent
- [ ] og:image présent
- [ ] og:image:alt présent
- [ ] twitter card présente

## Contenu

- [ ] un seul H1 généré par le template front
- [ ] pas de H1 dans `contentMarkdown`
- [ ] H2 bien structurés
- [ ] introduction complète
- [ ] article utile et non générique
- [ ] bloc “Le regard d’Art Home Déco”
- [ ] mention locale naturelle
- [ ] conclusion
- [ ] CTA final
- [ ] liens internes vers `/boutique` et `/contact`

## Qualité

- [ ] pas de keyword stuffing
- [ ] pas de fausses affirmations
- [ ] pas de ton trop commercial
- [ ] pas d’auteur fictif
- [ ] pas de données légales fictives
- [ ] orthographe de la marque : `Art Home Déco`
