# Editorial Style — Art Home Déco

## Ton

Le ton doit être :

- professionnel
- chaleureux
- élégant
- naturel
- accessible
- précis
- non agressif commercialement

## Style

Privilégier :

- phrases claires
- conseils concrets
- exemples liés à la décoration intérieure
- références naturelles à la montagne si pertinent
- vocabulaire sensoriel mais mesuré

## Markdown autorisé

Dans `contentMarkdown` et `brandPerspectiveMarkdown`, Gemini peut utiliser :

- `##` pour les H2
- `###` pour les H3
- paragraphes simples
- listes à puces si utile
- liens Markdown internes
- emphase légère avec `**texte**`

Ne pas utiliser :

- `#` pour le H1 dans le Markdown
- HTML brut
- scripts
- iframe
- style inline
- classes Tailwind dans le Markdown

## Exemples de bonnes formulations

“Dans un intérieur de montagne, une bougie aux notes boisées peut renforcer la sensation de refuge sans surcharger la décoration.”

“Chez Art Home Déco, nous privilégions les objets qui apportent une présence discrète : une belle matière, une lumière douce, une texture chaleureuse.”

## Formulations à éviter

- “incontournable”
- “révolutionnaire”
- “le must-have absolu”
- “la tendance ultime”
- “indispensable dans tous les intérieurs”
- affirmations absolues non vérifiées
